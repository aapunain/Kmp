# ADR-NNNN: Short title in the imperative

- **Status:** Proposed | Accepted | Superseded by [ADR-NNNN](NNNN-....md)
- **Date:** YYYY-MM-DD

## Context

What situation forced a decision. Include the constraint that made the obvious
option unworkable, and any measurement or error output that informed it.

## Decision

What we decided, stated plainly enough that someone can tell whether a given piece
of code complies.

## Consequences

What this makes easy, what it makes hard, and what it costs. Be honest about the
downside — an ADR with no downsides is not recording a real decision.

## Enforcement

How a violation is caught: a Gradle task, a compiler setting, or "review only".
If review only, say so explicitly.

## Alternatives considered

What else was on the table and why it lost. This is the section future readers
actually need, because it is the part nobody remembers.
